# PB96：MLBレギュラーシーズン公式成績の照合記録

対象ページ：<https://pibikuro96-web.github.io/html_pages/pb96/index.html>

## 集計範囲

- MLBに実出場した1996年度世代 **15選手**。MLB公式Stats APIから取得した **56年度・球団・種別行**（投手47行、打撃9行）。
- 年度・球団のユニークな組合せは50行。投手が実際に打席に立った年は投手・打撃の両方に記録します。
- MLB公式APIの `sportId=1`、`gameType=R`、アメリカンリーグ／ナショナルリーグを満たす試合の年度別球団スプリットのみを収録。
- **MiLB（AAA、AA、Aなど）・スプリングトレーニング・ポストシーズン・国際大会・NPB・独立リーグは一切含めない。** MLB球団傘下所属だけでは出場記録に含めず、公式MLB試合に出場した選手だけ計上します。
- 移籍年度の同一年・リーグ合計行は保存せず、球団別行のみを合算して通算を算出。**二重計上なし**。
- NPB個人ページと同じ項目数：打撃30、投手40（年度・球団列を除く）。MLBはNPBと別の表と通算で表示します。

## 公式資料・確認結果

- 取得元：<https://statsapi.mlb.com/api/v1/> と <https://www.mlb.com/>。
- 打撃は出場・打席・打数・安打・二三塁打・本塁打・打点・盗塁・三振・敬遠・打率・出塁率・長打率・OPS、失策（野手守備記録の合計）など。
- 投手は登板・先発・勝敗・ホールド・セーブ・投球回・被安打・与四球・敬遠・奪三振・球数・打者・被打率など。
- 投手の**47年度×球団行**で、公式ゲームログを年度別登板数・先発数・投球アウト数と突合。照合エラー：0件、差異：0件。
- **QS**は先発登板かつ6回（18アウト）以上・自責点3以下。**HQS**は先発登板かつ7回（21アウト）以上・自責点2以下としてゲームログから計算。
- QS率・HQS率は `達成数 ÷ 先発登板数 × 100`。先発0の年の率は0%ではなく「—」と表示。通算も合計値から再計算。
- HP・FIPなどMLB公式の同一意味で比較できる数値がない欄は「—」を表示し、値を捏造しません。
- 元データ 48行 → 再収集56行。追加8行、消失0行。API取得失敗0件。
